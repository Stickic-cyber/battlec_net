# v5：出生点与候选后果驱动的分裂教师

本轮保留 Spatial、GRU 两种教师。原移动网络、观测路径、共享主干和 GRU 全部冻结；新增分裂网络独立训练。其他决策仍由规则负责，动态喂养规则作为单独对照。

Spatial 起点是 `rl_v4/runs/teacher-split/spatial-ppo-4.pt`，GRU 起点是该目录的 `gru-initial.pt`，分别沿用此前选定的教师。两者的训练历史不同，因此本轮比较的是这两个现有教师的改进效果，不能把全部胜负差异归因于是否使用 GRU。

## 网络与动作

| 部分 | 输入及结构 | 是否训练 |
|---|---|---|
| 既有移动 | v4 全套空间、实体、95 维全局/历史、方向候选；256 维状态 | 否 |
| 出生点分支 | 29×7×7 尾部图；两层 32 通道 CNN、GroupNorm、SiLU，输出 64 维 | 是 |
| 上下文分支 | 新增 32 维上下文 + 冻结主干的 256 维输出 → 128 维 | 是 |
| 候选编码 | 每个候选 32 维 + 出生点 64 维 + 上下文 128 维；共享 MLP → 64 维 | 是 |
| 分裂时机 | 上下文、出生点、合法候选均值 → 是否分裂 | 是 |
| 分裂尺寸 | 共享候选编码 → 各尺寸得分 | 是 |
| 价值与辅助头 | 团队终局价值；候选子龙存活、增长、父龙存活预测 | 是 |

Spatial 共 2,670,156 参数，GRU 共 2,670,668 参数；本轮两者各训练 258,790 参数。没有增加大型通用主干。

动作是“继续原移动”或至多 5 个去重后的合法分裂尺寸。时机概率和条件尺寸概率相乘，形成归一化的 6 槽策略；贪心执行先比较分裂总概率与继续移动，再选择尺寸。规则应急分裂和供给保护分支照常执行。

GRU 每条龙独立维护 256 维记忆，所有存活回合都更新，新生清零。缓存的隐状态来自冻结网络，因此分裂训练无需反向传播穿过整段龙生涯。

## 新输入

尾部图复制旧 27 通道地图，增加可见自身占用、可见但未进入身体顺序估计的自身占用两个通道。修正仅作用于新图，不改变移动网络输入。

32 维上下文：回合、剩余时间、自身长度、单位占比、剩余名额、地图宽高、身体已知比例；主龙是否已知、报告年龄、长度、长度差、头部到主龙路径距离、路径是否已知；友军报告数、平均/最大长度、附近友军、可见敌头、敌头声呐；规则分裂建议；四种角色；头部空间/出口；尾部是否已知、是否可见、空间/出口、至主龙路径是否已知。

每候选 32 维：分裂标记、子龙长度、父龙剩余长度、子龙比例、规则推荐、最小子龙标记；身体已知比例、出生点是否已知、出生偏移 x/y、出口、空间、珍珠、生成点、未知边界；头部空间、出口、父龙空间长度比；至主龙估计时间、路径是否已知、送达余量；最近友军/敌军距离；切分位置是否已知、偏移 x/y；出生点附近友军、信息年龄、估计朝向 x/y、局部已知比例、剩余名额。

回合数同时存在于旧输入和新增上下文中。身体/出生位置来自各龙自身历史估计；搜索仅走已知地形和已知门连接，最多搜索 128/512 格。送达余量采用启发式等待与采集缓冲，不是真实未来收益，也不读取引擎私有状态。

“尾部已知 / 出生点已知”字段表示存在位置估计，并不保证整个身体序列完整；准确性需结合身体已知比例判断。不完整序列仍可能有出生点偏差。空间和出口是基于当前已知占用的静态估计，不能等同于子龙未来回合的精确合法动作数。

## 训练与评估

- PPO 使用终局团队胜/平/负 +1/0/−1，无折扣 Monte Carlo，按对局均衡权重。不给分裂次数、龙数或自爆次数奖励。
- 辅助任务预测动作后 20 回合内的子龙存活、观察到的正向净增长和父龙存活。短局未满观察窗时屏蔽未知标签。净增长是代理量，不冒充喂养来源。
- 对规则对局固定前缀，仅改一个分裂决定并重放完整后续；前缀哈希必须相同。只有最终胜负改变时才形成偏好标签。
- 每种架构两个训练种子、各四次更新；每次四场真实官方引擎对局，对手均为方案1。
- 先比较规则与积极扩张，再训练；验证比较两个训练结果与两个规则对照。另用配对验证选择动态喂养。选择文件写入后才运行独立测试及必要的原规则配对控制。
- 每次更新核对采样时与训练时的动作概率、价值，以及冻结主干哈希；源代码、地图、旧权重和配置均存入清单。

动态喂养使用预计返程时间启动汇合，并尝试通过现有声呐协议做接收确认。该规则是否采用由验证决定；它不会被默认为有效改进。

## 反馈优化阶段

参考训练中，部分批次超过八成决策来自第 300 回合以后，且原更新几乎没有改变贪心分裂决策。因此追加同数据对照：提高学习率和训练轮数；以及在相同更新强度下，对每局内各个 100 回合阶段均衡加权。二者均限制精确整体 KL ≤0.02、单阶段 KL ≤0.05，通过参数步长投影执行约束。开发集决定采用哪种方法，随后每个架构追加两批新的 on-policy 对局。

另比较动态喂养 v2：当长度达到 14 而被规则标记为局部 KING 的龙，获知更新鲜、更大的接收者，并进入可达的送达窗口时，也允许转为供给角色。该修正保持其余规则不变。喂养方案先在 4 局筛选，再在另外 4 局确认，合计得分必须严格高于原喂养才采用。

最终按 8 局完整策略验证结果锁定推荐架构，再进行双方配对的新种子测试。新测试仍使用 Colosseum、devil 两种地图几何，不能称为全新地图测试。`train-v5-full.cmd` 可按顺序续跑参考实验、反馈优化和最终审计；不要与已有训练进程同时启动。

追加验证还比较随机执行：训练后的策略随机采样，与相同冻结移动模型、未训练分裂头的随机先验使用相同对局和随机数设置。这样可以区分“学习有效”和“随机分配部分龙去分裂有效”。随机执行不新增模型架构，也不把未训练先验获胜记作学习收益；执行模式和随机种子配置一并写入最终策略文件。

验证同分时，随机策略优先保留未训练先验。若最终入选的是训练后的随机策略，新种子测试会再加入使用相同喂养规则的未训练随机先验，单独检查分裂学习的增益；这组独立测试不再改变已锁定的选择。

追加训练保留参考实验中真正改变胜负的单动作偏好标签及原有权重。GRU 的 schooltime/A 开发局已观察到一次“仅改一个分裂决定，失利变获胜”的干预；该标签可以监督特定局面，但是否泛化仍由后续验证决定。

`train-v5.cmd` 可启动/续跑；已完成对局和更新通过内容哈希校验后复用。训练教师在本机原生 Python 中推理，方案1使用官方沙箱；尚未进行教师提交沙箱预算适配或蒸馏。

## 参考验证后的最小保护对照

GRU 种子 9201 在八局参考验证中仅 2 胜 6 负，而积极分裂规则为 6 胜 2 负。前者 99 次战略分裂中有 85 次把长度 4 拆成 2＋2；子龙 20 回合内死亡为 13/99，积极规则为 3/51。这个观察不证明尺寸导致死亡，但提示应独立检查父龙是否保留得过短。

在任何独立测试开始前，为追加实验固定一个单因素对照 `parent_min=3`：仅在网络输出后屏蔽父龙剩余长度小于 3 的候选，再对原概率重新归一化；无合适分裂尺寸则继续移动。原网络输入、参数、训练过程、受保护的规则分裂均不改变。此约束只用于独立评估候选，不将受约束的动作混入原 PPO 数据。

两种架构分别比较“未训练先验＋该约束”和“追加训练模型＋该约束”的八局验证表现；其余候选保留，同分先保留原有候选，再优先未训练约束先验。若入选带约束的训练模型，独立测试追加相同约束、喂养和执行方式的未训练先验对照。只测试父龙长度 3，不继续搜索其他保护阈值。执行配置和权重一并保存，评估入口会读取 `parent_min`。
