# v5 优化总结：实验收束

**当前推荐：GRU 移动教师＋积极分裂规则＋原喂养规则。** 已按用户要求停止剩余实验，不继续搜索超参或追加对局。完整参考实验完成 192 局，追加阶段完成 84 局；追加整体协议提前终止，未生成假定完整的追加 `results.json`。

收益主要来自更积极的规则扩张。本轮训练的分裂网络尚未超过规则，不能把收益归因于新分裂网络学习。

## 最有用的结果

全部对手均为原始方案1。表中均保留各架构原有移动能力与原喂养规则。

| 方案 | 验证（8局） | 参考独立测试（8局） |
|---|---|---|
| GRU＋积极分裂 | **6胜2负** | **7胜1负** |
| GRU＋原分裂 | 1胜1平6负 | 4胜4负 |
| Spatial＋积极分裂 | 4胜4负 | 5胜3负 |
| Spatial＋原分裂 | 3胜5负 | 3胜5负 |

验证：dilemma、queen_of_spades，种子 9411/9417，双方位置。参考测试：Colosseum、devil，种子 9511/9517，双方位置；参考配置在测试前冻结。GRU 根据验证表现获得推荐。样本少且只对方案1有效，7/8 不应解释成排行榜胜率或稳定的总体胜率。

## 学到了什么

- 增加尾部局部图、阶段/团队上下文、候选分裂后果，并使用分层时机/尺寸决策后，分裂学习仍未胜过积极规则。当前不值得继续堆参数或微调同一批超参。
- 原移动主干、移动头与 GRU 始终冻结；本轮结果不能评价重新训练移动网络的潜力。
- 失败复盘发现大量长度4拆成2＋2，以及较高的子龙早亡比例。这是后续分析线索，尚未证明因果；已完成的 Spatial 父龙保护对照也未提升胜率。
- 一个固定前缀的单动作干预由负变胜，支持该局面下3＋3分裂，但这只是单一开发状态，不足以证明网络学会可泛化的分裂策略。

## 保存与核验

推荐配置在 `best-policy.json`：权重 `runs/structured-split/gru-initial-9201.pt`，`controller=aggressive`、`feeding=original`、确定性执行。该权重保留原 GRU 移动能力；分裂由规则接管。权重、控制模式和喂养配置必须一起使用。

运行 `evaluate-v5-best.cmd --describe` 可核验权重及源码哈希，不启动比赛。源码清单引用追加阶段的 `manifest.json`，仅用于运行版本核验；推荐成绩与权重来源均为已完成的参考实验。

参考192局已完成回放审计，执行及谱系错误为0；追加84局完成批次的记录中执行及谱系错误也为0，但未对追加阶段重新执行全量回放审计。明细见 `runs/refined-teachers/closure.json`。教师仍是本地原生 Python 版本，未蒸馏、未提交，官方沙箱预算尚未验证。

本轮到此结束。如果以后继续，优先针对更强规则对手检验当前推荐策略、分析具体失败局；在出现明确的新信号前，不恢复大规模分裂训练。
